## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- pinterest-growth-manager
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/pinterest-growth-manager /tmp/pinterest-growth-manager
mkdir -p ~/.claude/skills && cp -r /tmp/pinterest-growth-manager/skills/pinterest-growth-manager ~/.claude/skills/
```

**Per project:** copy `skills/pinterest-growth-manager` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/pinterest-growth-manager/SKILL.md) into your rules or system prompt.
